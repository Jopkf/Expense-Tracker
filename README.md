# Expense Tracker

## Информация об авторе
**Имя и фамилия** Никита Рябицкий
**Дата создания** Май 2026

## Описание
Приложение для учета личных расходов с графическим интерфейсом.
Позволяет добавлять расходы, фильтровать их и считать сумму за период.

## Возможности
- Добавление расходов (сумма, категория, дата)
- Фильтрация по категории и дате
- Подсчет общей суммы
- Сохранение данных в JSON

## Как использовать
1. Запустите программу:
   python main.py
2. Введите сумму, категорию и дату (формат: YYYY-MM-DD)
3. Нажмите "Добавить расход"
4. Используйте фильтры при необходимости
5. Нажмите "Посчитать сумму"

## Примеры
- Ввод: 500, Еда, 2026-05-01
- Ввод: 200, Транспорт, 2026-05-02

Фильтр:
- Категория: Еда
- Период: 2026-05-01 — 2026-05-10

Результат: 500
